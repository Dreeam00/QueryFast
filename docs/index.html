See it in Action

A fully reactive Todo application in just 15 lines of code. No build tools required, just raw power.

const state = Q.state({ list: [], input: "" });

function todoApp(parent) {
  const root = parent.el("div.q-todo");
  
  const input = root.el("inp.q-input")
    .on("input", el => state.value.input = el.value);

  root.el("btn.q-btn").text("Add Task")
    .on("click", () => {
      state.value = { 
        list: [...state.value.list, state.value.input], 
        input: "" 
      };
      input[0].value = "";
    });

  root.el("ul.q-list").bind(state, s => 
    s.list.map(t => `
  • ${t}
    • `).join(""), 
    'html'
  );
}

Q("#demo-area").el(todoApp);

    API Reference

    Q(selector)
    The universal cursor. Wraps a CSS selector or DOM Node into a chainable QCollection.
    .el(arg, ...args)
    The Creator.
    - String: Creates DOM (e.g., "sec.hero") and appends to parent.
    - Function: Calls component with (parent, ...args).
    .text(value?)
    Atomic text content update. Chainable.
    .bind(state, map, mode)
    The reactive bridge. Modes: text, html, attr, class, css. Updates UI when state changes.
    Q.state(initial)
    Creates a reactive proxy. Magic happens here.
